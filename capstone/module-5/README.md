# Module 5 Capstone Seed Pack

This folder provides starter data and structure for Module 5 so learners can build from a meaningful baseline.

## Options

- `delivery-dashboard/seed/sprint-data.json`
- `product-dashboard/seed/product-signals.json`
- `custom-tool/seed/transcript-sample.md`

## Facilitator guidance

- Learners can start with seeded data and then extend.
- Keep scope small for first build (one dashboard/tool that works end-to-end).
- Encourage learners to commit frequently and use PR reviews even in solo flow.

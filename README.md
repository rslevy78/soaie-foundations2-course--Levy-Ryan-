# SOAIE Foundations 2 Course Source Repo

This is the source repo for the Module 2 Git lab.
Learners will fork this repo, clone their fork locally, and use it as the starting point for the Git collaboration workflow.

## Working model
- Source repo: this repository
- Learner copy: personal fork
- Local workspace: clone of the fork

## Seeded lab content
- `meeting-notes/20260706-release-planning-summary.md`
- `backlog/epic-reporting.md`
- `backlog/user-stories/us-101-export-customer-report.md`
- `backlog/user-stories/us-102-sort-report-columns.md`
- `backlog/user-stories/us-103-save-report-filters.md`
- `src/report-columns.js`

## Facilitator flow
- Keep the repo forkable so learners can create their own copy.
- Update seed content through PRs so the course keeps its review flow.
- Use a seeded teammate branch for the reviewer exercise.
- Keep the slides, lab prompts, and repository seed aligned.
